# Maszynka.pro Node.js Discord Bot

Skopiuj `config.example.json` jako `config.json`, uzupełnij ID kanałów/ról i ustaw `DISCORD_TOKEN` w Pterodactylu.

Jeżeli config nie jest gotowy, bot kończy pracę z komunikatem:

`Skończ mnie konfigurować w ./config.json`

## Prefix Commands

- `m!help`
- `m!weryfikacja`
- `m!ticket`
- `m!configcheck`

## Slash Commands

- `/ping`
- `/help`
- `/userinfo`
- `/serverinfo`
- `/botinfo`
- `/avatar`
